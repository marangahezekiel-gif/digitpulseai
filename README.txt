DigitpulseAi - front end (no backend)

Open index.html in a browser, or upload the folder to any static host.

Edit at the top of the <script> in index.html:
  APP_ID  - Deriv app id (set the OAuth redirect URL to your live site address in Deriv's dashboard)
  WA, USDT, MPESA, PAYEE - payment and WhatsApp details
  PLANS - plan names, prices, features

Note: approval status is saved in the visitor's own browser (localStorage) until a backend is added.
